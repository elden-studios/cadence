# Cadence v1.2 Soft Paywall + Trial — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Cadence's restrictive free tier with a soft paywall model: 7-day free trial + free watermarked invoices + Pro for watermark-removal/Reports/CSV.

**Architecture:** Apple's StoreKit drives all trial timing + auto-renewal. A new 3-case `Entitlement` enum (`.free` / `.trial(daysRemaining:)` / `.pro`) replaces the boolean `isPro` for gating fine-grained features. The PDF renderer gains an optional `watermark: String?` field on `InvoiceTemplateData` — present for free users, nil for trial/Pro. No new `@Model`, no migrations.

**Tech Stack:** SwiftUI + StoreKit 2 + SwiftData + BillableCore Swift Package + Xcode 26 / iOS 26.5 + GitHub Pages (Jekyll) for legal URLs.

**Spec:** `docs/superpowers/specs/2026-05-26-v1.2-soft-paywall-and-trial-design.md`

**Review pattern (hybrid):**
- **2-stage review** (paid product surface): Task 1 (StoreKit Config) · Task 2 (Entitlement refactor) · Task 4 (Watermark renderer)
- **Combined review**: Task 3 (open free tier) · Task 5 (remove-watermark trigger) · Task 6 (button + copy) · Task 7 (legal URLs)

- [ ] **Step 2.3: Update refreshEntitlements to populate `entitlement` instead of `isPro`**

Find `refreshEntitlements()` (or wherever `isPro = true/false` is set). Currently it likely does something like:

Replace with:

```swift
public func refreshEntitlements() async {
    guard let transaction = await currentActiveTransaction() else {
        entitlement = .free
        return
    }
    // Determine if the active transaction is still inside its intro-offer period.
    if let intro = await currentIntroOfferDaysRemaining(transaction: transaction) {
        entitlement = .trial(daysRemaining: intro)
    } else {
        entitlement = .pro
    }
}

/// Returns the number of days remaining on the intro-offer period, or nil if
/// the transaction is not currently in an intro offer.
private func currentIntroOfferDaysRemaining(transaction: Transaction) async -> Int? {
    // Apple exposes the intro offer's period via Transaction.offer.
    // If the transaction is currently in its intro offer period:
    //   daysRemaining = ceil((purchaseDate + 7 days - now) / 86400)
    guard transaction.offer?.type == .introductory else { return nil }
    let now = Date()
    let trialEndDate = transaction.purchaseDate.addingTimeInterval(7 * 24 * 60 * 60)
    guard now < trialEndDate else { return nil }
    let secondsRemaining = trialEndDate.timeIntervalSince(now)
    let daysRemaining = max(1, Int(ceil(secondsRemaining / 86_400)))
    return daysRemaining
}
```
